# Editor de video — cómo obtener el APK
1. Crea un repositorio privado en GitHub (nuevo, distinto al de la biblioteca PDF).
2. Sube TODO el contenido de la carpeta `VideoEditor` (incluidas `.github`, `app`, `gradle`, `keystore`).
3. Pestaña Actions → "Build APK" → descarga el artefacto **VideoEditor-apk** → instala el APK.
Los videos exportados se guardan en la Galería, carpeta Movies/VideoEditor.
